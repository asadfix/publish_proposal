\section{Step 5: Linking}
\label{sec:linking}

If partial invariance holds, we link the platform scales. We claim linking, not equating: equating requires that transformed scores be interchangeable, a standard machine-labelled sentiment across platforms cannot meet, so the weaker linking relation is the honest target \citep{kolen2014}. The linked object is a platform-level quantity, the platform-specific latent means and variances under the partial-invariance model, not any per-post score. The pre-identified fiscal events serve as common stimuli rather than common items: different posts by different authors are scored on each platform, which in Kolen and Brennan's taxonomy is a moderation design, the weakest linking category, and we say so plainly. The link is identified only under the assumption that latent sentiment toward each anchor event is equal in expectation across platform populations after the Step 4 composition adjustment; where that assumption is doubted, the crosswalk removes population differences along with measurement differences, and we report both indices for that reason. The September 2022 mini-budget is the centrepiece anchor, with the 48-hour and two-week windows defining the linking samples. Purification is ex ante: the rule for screening anchors for differential functioning is fixed before any linking function is estimated \todo{state the purification statistic and threshold here; an unstated rule cannot be ex ante}, so anchors cannot be selected to flatter the result. Sensitivity is leave-one-event-out: we re-estimate the linking function dropping each anchor event in turn and report the spread; a link that depends on a single event is reported as such, not smoothed over.

The design has an honest fork. If Step 3 shows non-invariance too severe to support even partial-invariance linking, we do not link. The deliverable then becomes platform-specific sentiment series plus the demonstration that a pooled cross-platform index is unsupported for this construct. Either branch is a finding: a crosswalk with quantified uncertainty, or evidence that none exists.
